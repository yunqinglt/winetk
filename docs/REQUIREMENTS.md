# 需求及验收边界

## 用户已经确认的范围

| 项目 | 结论 |
| --- | --- |
| 显示方式 | Wine 窗口通过终端图形协议直接显示，不使用 X11/Wayland 显示这些窗口 |
| 后端 | 预留协议接口，优先 Kitty Graphics Protocol |
| 首版程序 | 普通 Win32/GDI 桌面程序优先 |
| 最终目标 | 本机 `~/.local/share/Steam/steamapps/common/Limbus Company`，Unity IL2CPP 游戏；需覆盖其实际使用的 GPU 图形 API |
| 窗口模型 | 单个终端画布，内部合成全部 Windows 窗口 |
| 部署 | 首版本机运行 |
| 交互 | 首版包含键盘和鼠标 |
| 当前交付 | GDI、离屏 WGL/WineD3D D3D8/D3D11、Unity Mono/IL2CPP 标题界面、Steam TUI 与持久化设置；客户区画布、顶部留行和启动时实际分辨率适配 |
| 终端标题 | `(0,0)` 显示启动的可执行文件名，保留首行并校正鼠标映射 |
| Kitty 修改 | 用户允许为图形转发记录修改 Kitty 源码；优先验证现有协议与调试记录能力，必要时在独立源码树修改 |

## 首版必须满足的行为

1. Wine 使用专用显示驱动，图形呈现链路不连接 X server 或 Wayland compositor，不以 Xvfb、嵌套 compositor、宿主截图作为替代实现。
2. 会话中的所有顶层窗口、对话框、菜单、工具提示归入同一逻辑桌面；正确处理遮挡、Z 序、移动、最小化、关闭、重绘。子窗口遵循 Wine 的绘制和裁剪机制，不能重复合成。
3. 终端接收像素画面，支持真实 GDI 文本和控件，不把 GUI 改写成字符近似图。
4. 支持文本录入、常见快捷键、方向键、修饰键、键释放；支持鼠标点击、双击、移动、拖动和滚轮。处理焦点与鼠标捕获，避免失焦后卡住按键。
5. 终端缩放时维护确定的坐标映射。画布跟随应用报告的客户区尺寸，小终端等比缩放并留边；虚拟显示模式与终端画布尺寸分别管理。
6. 多个 Wine 进程可以同时贡献窗口，不能由它们各自读写终端。应用的 stdout/stderr 和 Wine 日志不得混入图形协议流。
7. 正常退出、应用崩溃和可处理信号下恢复 termios、备用屏、键盘/鼠标模式，释放本会话图像。SIGKILL 无法保证清理，必须提供可操作的终端恢复说明。
8. 后端没有必要能力时给出明确错误；不能默默改走 X11/Wayland。设备能力通过协议探测，不能仅凭 `$TERM` 推断。

## 范围解释与暂定选择

Wine 侧不依赖 X11/Wayland；终端模拟器自身用何种宿主显示系统不受此限制。未来 GPU 路线也必须遵守这个边界。
本项目是 Wine 显示驱动与终端会话系统，不是通用现有桌面的截图转发器。

最终目标的本机文件证据、GPU 候选路线和分阶段验收见 [Limbus Company 目标分析](TARGET-LIMBUS.md)。
M1 动画和 GDI 首版只是中间成果；最终需验证游戏真实画面与键鼠交互，不能用 GDI surface 成功推断 Direct3D 已支持。

首版暂定 Linux x86_64 主机、现代 WoW64，同时准备 x86/x64 PE 工具链。
开发语言暂定 C，以便复用 Wine 的构建、ABI 和调试方式；终端协议、IPC 和合成器分层，后续可独立替换。
上述平台和语言选择是开发建议，不是用户已明确指定的额外要求。

SSH、tmux/screen 穿透、多终端窗口、多显示器、剪贴板同步、中文输入法组合、系统托盘、触摸/手柄/游戏 Raw Input 不作为首版完成条件。
UTF-8 文本和粘贴应有基础路径；完整 IME 预编辑、候选窗和非拉丁键位映射需要单独验收，不能将普通文本输入等同于完整 IME 支持。

## 可核验的首版验收

- 清除 `DISPLAY`、`WAYLAND_DISPLAY`，使用项目构建和隔离 prefix，启动项目 GDI smoke 程序与 Wine Notepad。
- 同画布同时显示两个进程的窗口、模态对话框和弹出菜单；遮挡、拖动、关闭后无残影。
- 完成输入文字、Ctrl+A/C/V 的应用内操作、Shift 选择、滚动和拖动；焦点切换后不粘键。跨宿主剪贴板同步不在此验收内。
- 改变终端尺寸，验证留边、缩放和鼠标命中一致。
- 用调用跟踪和驱动日志确认 Wine 显示进程不连接 X11/Wayland socket；单纯清空环境变量并不足以证明。
- 记录尺寸、终端版本、帧率、传输字节率、合成/编码/排队耗时、内存和交互延迟；性能目标在真实终端基线测量后确定。

## 后续需要逐步确定的交付细节

最低终端版本和系统发行包仍待确定。当前默认大小与缩放策略见 [TUI 配置](TUI.md)，独立代码采用 GPL v3，Wine 补丁许可见 [NOTICE](../NOTICE.md)。
这些不阻塞 M1；进入相应里程碑时应把选择记录为验收条件。Limbus Company 的分辨率、可接受帧率/输入延迟以实际基线测量后确定。
